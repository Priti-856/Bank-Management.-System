# Bank Management System (C++)

Console-based banking application using C++ OOP and File Handling.

## Features
- Create Account
- Login
- Check Balance
- Deposit
- Withdraw
- Borrow Loan
- Return Loan
- Update Details
- Transfer Money
- Delete Account
- Save & Load Data
- Admin View All Accounts

## Compile
g++ main.cpp -o bank

## Run
./bank
